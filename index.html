Common questions

Quick answers

Do I need an account?

No. Smart Journey does not require sign-in.

Where is my trip stored?

Your trip workspace is stored on the device using the app’s local storage.

How do I remove my data?

Use Clear trip to remove the current trip workspace, or Delete all local data to remove the app’s local database files, keys, and cached artifacts from the device.

Does trip parsing use a remote AI service?

No. Trip parsing uses an embedded on-device model with deterministic extraction. There is no remote inference fallback for trip parsing.
